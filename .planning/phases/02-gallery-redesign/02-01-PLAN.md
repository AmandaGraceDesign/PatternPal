**Tab strip (GALL-01):**
- Use pill style: active = `bg-[#d97706] text-white shadow-[0_2px_8px_rgba(217,119,6,0.4)]`, inactive = `bg-white/10 text-white/70 hover:bg-white/20`

- Use `rounded-full` for pill shape, `text-[11px] font-semibold whitespace-nowrap`
- Hide scrollbar: use inline `style={{ overflowX: 'auto', scrollbarWidth: 'none' }}` on the tab container. Also add a CSS comment noting WebKit needs `::webkit-scrollbar { display: none }` in globals if not already handled. The inline `scrollbarWidth: 'none'` covers Firefox/Chrome standards.
- Drive tab keys from the `categories` array and `categoryLabels` map (already in current code — reuse them)

**Gallery grid (GALL-02, GALL-03, GALL-04):**
- Grid: `grid grid-cols-2 sm:grid-cols-3 gap-3 p-4`
- Each card: `group cursor-pointer rounded-xl overflow-hidden bg-gray-50 transition-transform hover:scale-[1.02] active:scale-[0.98]`
- Card thumbnail: wrap `MockupRendererV2` in `<div className="aspect-square overflow-hidden bg-gray-100">` for visual grid consistency
- Card label area below thumbnail: `<div className="px-2 py-1.5">` with:
  - Template name: `text-xs font-semibold text-[#294051] truncate`
  - sizeLabel: `text-[10px] text-[#d97706] font-medium truncate` (amber for pop — GALL-03)
- `onClick={() => onSelectMockup(template.id)}` on the outer card wrapper (not inside canvas)

**Staggered render initiation (performance — GALL-02):**

- Pass `patternImage={index < revealedCount ? image : null}` to each `MockupRendererV2`
- Clean up timers on unmount/re-trigger

**Empty state:**
