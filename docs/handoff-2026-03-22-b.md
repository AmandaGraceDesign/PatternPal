# Handoff: Multi-Zone Mockup System (cont.) — 2026-03-22-b

## What was done this session

### 1. Fixed zone mask alignment for tshirt-dress
- **Problem**: White band gap between bodice and skirt zones — pattern wasn't reaching the seam
- **Root cause**: `patternArea` coordinates were guessed estimates, way off from actual mask white-pixel bounds. Also, perspective warp and displacement were being applied on top of a photo-based mockup that already has natural perspective/texture
- **Fix**: Used Pillow to scan actual mask pixel bounds:
  - Bodice white region: x=453..1412, y=421..1316
  - Skirt white region: x=430..1436, y=1306..2111
  - Masks meet at y≈1307 with 1px anti-aliased transition
- Set `patternArea` to match exact mask bounds with 10px overlap at the seam to cover anti-aliased transition pixels
- Set perspective to 0/0 and displacement to 0 for photo-based mockup (photo already has natural perspective and fabric texture)

### 2. Updated physical dimensions for tshirt-dress
- Researched girls size 5 (kids, not 5T) dress measurements
- Updated `physicalSize` from `{ width: 14, height: 22 }` to `{ width: 13.5, height: 20.5 }` (accurate for size 5 kids A-line dress)
- Added `sizeLabel` field to `MockupV2Template` type for human-readable display
- Set `sizeLabel: 'Size 5 Kids (13.5×20.5")'` on tshirt-dress template

### 3. Updated MockupGalleryModal
- V2 mockup cards now show `sizeLabel` when available, falling back to raw dimensions

## Key learning
- For photo-based mockups: set perspective and displacement to 0. The photo already has natural perspective and fabric texture. Multiply blend handles the rest.
- Always use Pillow (or equivalent) to scan actual mask pixel bounds rather than guessing coordinates visually. The `patternArea` must encompass the mask's white region precisely.
- Anti-aliased mask edges need ~10px overlap between zones to prevent seam gaps.
